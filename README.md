# ✦ Cordel Moderno

Projeto de estudo desenvolvido com **HTML5 e CSS3**, com foco na criação de **imagens de fundo com efeito parallax**, inspirado no estilo do cordel nordestino.

## 🔗 Demonstração

⌁ Acesse o projeto online:  
[https://maria-paula-lopes-dev.github.io/projeto-cordel-moderno/](https://maria-paula-lopes-dev.github.io/projeto-cordel-moderno/)

## ✧ Sobre o projeto

O **Cordel Moderno** é um projeto de estudo que tem como objetivo explorar o efeito **parallax** utilizando apenas **CSS**, valorizando a leitura e a estética do cordel tradicional em uma abordagem moderna.

O conteúdo é baseado no poema *Cordel Moderno*, de **Milton Duarte**, e o layout foi pensado para manter clareza visual e boa experiência de leitura.

### ◈ Objetivos do projeto

▸ Trabalhar o efeito **parallax** utilizando apenas CSS  

▸ Explorar imagens de fundo fixas para criar profundidade visual  

▸ Praticar **HTML semântico**  

▸ Separar corretamente conteúdo e estilo  

## ✧ Conceitos aplicados

▸ Uso da propriedade `background-attachment: fixed`  

▸ Imagens de fundo com efeito parallax  

▸ Estruturação semântica de textos longos  

▸ Organização visual focada na leitura  

## ✧ Tecnologias utilizadas

▸ HTML5  

▸ CSS3  

▸ Background-image  

▸ Parallax com CSS  

## ✧ Aprendizados

Durante o desenvolvimento deste projeto, foram aprofundados os seguintes conhecimentos:

▸ Criação de efeito parallax apenas com CSS  

▸ Uso de imagens como plano de fundo  

▸ Organização semântica de conteúdos extensos  

▸ Separação entre estrutura e estilização
